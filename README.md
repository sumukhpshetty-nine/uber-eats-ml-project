# Uber Eats Operational & Customer Intelligence System

## Project Overview

This project builds an end-to-end machine learning system for a food delivery marketplace.

The system will analyze:

- Customer behavior
- Restaurant performance
- Customer sentiment
- Delivery time
- Tip amount
- Hourly order demand

## Machine Learning Components

### 1. Customer and Restaurant Segmentation
- K-Means
- DBSCAN
- PCA

### 2. Customer Feedback Analysis
- Text preprocessing
- TF-IDF
- Sentiment classification
- VADER

### 3. Regression
- Delivery time prediction
- Tip prediction

### 4. Time Series Forecasting
- ARIMA
- Prophet
